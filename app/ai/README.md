# Module IA optionnel (après la Phase 6)

Réservé. Exigences non négociables :

* toute valeur (résolution, précision, emprise) doit être **liée à un extrait source** ;
* les informations non vérifiées restent marquées `verified = 0` jusqu'à validation humaine ;
* chaque sortie cite les références et liens vers les sources originales ;
* aucune invention : en cas d'absence d'information, la réponse est « non documenté ».
